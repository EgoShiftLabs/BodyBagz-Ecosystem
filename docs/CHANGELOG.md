# BodyBagz Ecosystem — Changelog

## V0.2.0 — Local integration hardening (November 17, 2026)
- Added a meaningful non-JavaScript four-module overview and a meta Content Security Policy.
- Corrected duplicate pairing form IDs and routed submissions through a shared class with unique case IDs.
- Extended Forge to require an explicit human revision to original project deliverables, user value and risk plan. Unreviewed placeholder research text cannot advance to review preview.
- Added a required confirmation that education passes and Forge reviews are LOCAL PREVIEWS, not verified certificates or official approvals.
- Preserved research provenance URLs in Forge drafts; source evidence remains marked unverified.
- Enhanced browser-only session navigation to restore the open lesson after refresh.
- Added 2 optional, backward-compatible fields to the V1 proposal envelope: \`reviewPrepared\` and \`sourceUrl\`; no breaking schema renames.
- Kept the original localStorage key and schema identifier. Older V0.1 review-preview proposals lacking explicit revised acknowledgement revert to editable drafts on reload; their content remains intact.
- Tightened manual external source URLs to HTTPS only.
- Expanded Playwright desktop/mobile QA to failure/retry, source/creator CRUD, exports, stage confirmations, multiple pairing cases, delete cascades and non-JS landing.
- Published an independent repository extraction checklist.

**Not implemented:** Verified identities, server-authorized certificates, on-chain NFT minting, live trading/KOL APIs, official program submissions, verified BAGZ pairing eligibility, wallet signing or transactions.

## V0.1.0 — Initial connected demonstration
- Four connected modules and static premium hub.
- Six builder learning tracks and 30 self-scored questions.
- Manual sourced research and local KOL bookmarks.
