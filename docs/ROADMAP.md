## V0.3+ — Earn the right to expand
- [ ] Verified credentials and builder program with transparent requirements and appeals
- [ ] Community feedback loops and mentorship
- [ ] Authorized developer project collaborations and optional token pair support, if legal and technically eligible
- [ ] Link project execution outcomes, education outcomes and community welfare metrics
- [ ] Independent UX/product-market-fit validation before adding fees, locked tokens or access restrictions

### Non-goals
No invented profitability, no fabricated KOL/trending claims, no automated token promotions, no paid certificate shortcuts, no hidden sponsorship, no open-ended transaction permissions and no implied investment advice.
